# 口口记 · 三餐与加餐计数器

一个轻量的静态网页 App / PWA，记录早餐、午餐、晚餐和加餐吃了多少口。

## 使用

- 点击“吃了一口”记一口；误点用“减一口”，或直接修改本餐口数。
- 三餐与加餐独立计数，支持标记这一餐记好了、历史补记、七日概览；一天内多次加餐累计在加餐中，没有加餐可留空。
- 在设置中导出或导入 JSON 备份。同日同餐冲突时保留修改时间更新的记录。
- iPhone：在 Safari 打开 → 分享 → 添加到主屏幕。首次联网打开后可离线使用。

## 数据和隐私

应用和源代码公开，个人记录仅保存在当前浏览器的 localStorage（键名 `koukouji.bites.v1`），不会发送到 GitHub 或其他服务器。无账号、无统计、无第三方字体或脚本。新增加餐保留原有数据结构和存储键，旧三餐记录及旧备份均可继续使用。

不同手机、浏览器、网址、主屏幕运行环境之间，不保证共享记录。换设备、清理网站数据或切换使用环境前请导出备份，再到新的环境导入。清理网站数据会清除记录。

只记录口数，不设统一口数上限，也不把口数换算成热量。

## 部署

纯 HTML、CSS、JavaScript，无需安装依赖或构建。GitHub Pages 从 `main` 分支根目录发布。图标为180/192/512像素PNG，资源使用相对路径，Service Worker 只管理本应用作用域与缓存。

本地预览：`python3 -m http.server 8765`。
